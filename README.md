# KOTI 1V1 Basketball Tournament

Public sponsor-facing website for 1V1 King of the Islands.

## Contents

- English business website for sponsors, venue partners, city partners, media partners, and players.
- Season 1 impact data, Season 2 city schedule, champions, social reach, and partnership sections.
- KOTI brand visuals and AI-created mall activation visualization.

## Deployment

This repository is prepared for GitHub Pages. If Pages is not already active, open repository Settings > Pages and choose GitHub Actions as the build source.
